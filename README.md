# Конструктор сметы

Прототип веб-приложения для строительной компании (ремонт квартир): прораб оцифровывает замеры на объекте, система автоматически считает смету, менеджер правит её и формирует коммерческое предложение.

## Как это работает

1. **Прораб** создаёт объект (адрес, заказчик, высота потолков), добавляет комнаты, размеры, окна/двери/балконные блоки и отмечает виды работ (с долей помещения: 100/75/50/25%).
2. Объём работ считается автоматически: площадь стен (периметр × высота − проёмы), пол, потолок, плинтус, откосы.
3. **Менеджер** получает готовую смету, правит объёмы и цены, добавляет свои позиции, ставит скидку.
4. Формируется коммерческое предложение для клиента.

## Запуск

Один файл без сборки: откройте `index.html` в браузере. Данные хранятся в `localStorage`.

## Статус и ограничения

- Расценки в справочнике `WORKS` условные, заменить на реальный прайс.
- Нет сервера: передача объекта от прораба менеджеру пока в рамках одного браузера.
- Нет выгрузки PDF и расчёта материалов.
